# Credits

The additive right-retraction criteria for extension and contraction of left ideals
and descent of left Noetherianity were first formalized by the Formal Frontier
group-rings contributors. This library reuses their formalization, built on Mathlib.

Two-sided ideal coatomicity builds on Mathlib's two-sided ideal API by
Jujian Zhang and its order-theoretic Zorn API by Yury Kudryashov. The
simple-quotient example uses Mathlib's ring congruence correspondence.

This development is by Formal Frontier Agents using AI assistance.
